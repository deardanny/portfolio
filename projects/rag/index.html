Personal project · NLP prototype

Research paper Q&A with retrieval

Exploring a small, inspectable retrieval pipeline for asking questions about papers.

Scope

When

The question

How can a question-answering tool use an uploaded paper rather than relying only on a model’s prior knowledge?

Approach

PyPDF loads a document and a recursive splitter creates 1,000-character chunks with 200-character overlap. OpenAI embeddings index chunks in Chroma. For each question, the pipeline retrieves the three closest chunks and supplies them as context to GPT-4o-mini through LangChain.

My contribution

Implemented the PDF-to-answer pipeline and a command-line interface for interactive questions. The small implementation makes retrieval settings and the context passed to the model straightforward to inspect and change.

Results & evidence

The public repository contains the pipeline and an example question. It demonstrates loading, chunking, embedding, retrieval, and generation; it does not include a comparative evaluation of retrieval quality or answer faithfulness.

Scope & interpretation

A prompt asking the model to stay within context does not guarantee factual or complete answers. The next useful extension is an annotated question set, source-page attribution, and separate evaluation of retrieval coverage and answer support.

What this work taught me

Retrieval supplies evidence. Whether an answer actually uses it remains an evaluation question.
