ABOUT THIS WORKSPACE

A working dashboard on synthetic data.

The interface and all 700 records were created for this portfolio. Brands, products, ratings, channels, text and labels are fictional. No company screens or source records are published.

Filters, charts, counts, drill-through and exports are calculated from the same records in your browser. The summary uses deterministic templates; no live AI service, company system or external database is connected.

These values demonstrate the analysis workflow. The project’s reported outcomes appear separately in the case study.
